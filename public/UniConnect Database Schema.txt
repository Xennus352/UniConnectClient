## Appendix: System Architecture
================================================================================

### Final Database Layer
-----------------------------------------------------------------
PostgreSQL    | Core university data (Users, Students, Staff, 
              | Courses, Classes, Timetables, Attendance, Exams).
-----------------------------------------------------------------
Convex        | Realtime & community data (Inbox, Chat, Posts, 
              | Events, Notifications).
-----------------------------------------------------------------
Supabase      | File storage (Inbox, Chat, Post, Event attachments).
Storage       |
-----------------------------------------------------------------

### Data Flow
PostgreSQL ---> (user_id references) ---> Convex ---> (storage_path) ---> Supabase Storage
